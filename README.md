# Pigeon personal website

Pagina personale per `pigeon.is-a.dev`, pronta per GitHub Pages.

## Pubblicazione

1. Crea su GitHub un repository pubblico chiamato esattamente `vale-coder.github.io`.
2. Carica `index.html` nella root del repository.
3. Apri **Settings → Pages** e scegli **Deploy from a branch**, branch `main`, cartella `/ (root)`.
4. Attendi che `https://vale-coder.github.io` sia online.
5. Segui la procedura ufficiale di is-a.dev per richiedere `pigeon.is-a.dev` con un record CNAME verso `vale-coder.github.io`.

Il file `CNAME` va aggiunto al repository quando il dominio è stato approvato e collegato nelle impostazioni di GitHub Pages.

## Controlli prima della richiesta is-a.dev

- Il sito deve essere già raggiungibile su `https://vale-coder.github.io` e sufficientemente completo.
- Deve rimanere personale, non commerciale e legato allo sviluppo software.
- La descrizione della PR deve conservare integralmente il template ufficiale e includere il link live.
- Nel campo `owner` del file `domains/pigeon.json` va aggiunto un contatto reale, per esempio `email`, `discord` o un altro profilo accettato.
- Il richiedente deve avere almeno 13 anni e fornire informazioni veritiere.
- La richiesta va compilata personalmente dal titolare dell'account; is-a.dev può respingere PR create tramite AI.
